Пошаговый план

01

Поставь Claude Code и выбери модель

  • Скачай десктопное приложение Claude с официального сайта → открой Claude Code, новую чистую сессию
  • Справа внизу выбери модель Fable 5
  • Уровень усилий (effort): Extra - лучший баланс. Чем ближе к правому краю, тем больше жрёт токенов
02

Подключи Higgsfield MCP

  • В Claude Code: Customize → Connectors → Add → Add custom connector
  • Название: Higgsfield, в поле Remote MCP server URL вставь адрес:
https://mcp.higgsfield.ai/mcp
  • Жми Add → тебя перекинет в браузер → жми Allow
  • Убедись, что залогинен в аккаунт Higgsfield - без него авторизация не пройдёт
  • Проверка: наведи на коннекторы → у Higgsfield включена галочка. Видишь Disconnect - всё подключено
  • Higgsfield даёт триал 3 дня - привязываешь карту, платить сразу не нужно
💡 Между делом: лично я беру на маркетплейсах готовый доступ к Higgsfield за ~$15 - выходит около 600 кредитов, хватает с запасом на все сайты из видео.
03

Найди референс (опционально)

  • Зайди на awwwards.com - там сайты, которые выигрывают награды
  • Понравился сайт → Visit Site → скопируй адрес → скажи Клоду «сделай мне что-то похожее на этот сайт»
  • Или собирай своё оригинальное по промптам из пака выше
04

Собери сайт одним промптом

  • Скопируй промпт под свою нишу из пака (в видео - Промпт 02, субмарина)
  • Вставь в новую сессию Claude Code → отправь
  • Дальше он всё сам: проверит баланс Higgsfield, сгенерит видео через Seedance 2.0, порежет на кадры, соберёт сайт и откроет на localhost
  • Просто дай ему поработать пару минут
⚙️ Настройки генерации: Seedance 2.0, std-режим, 16:9, без звука. Для тестов ставь 720p - 1080p стоит в два раза дороже.
05

Портфолио из одной фотографии

  • Возьми Промпт 03 из пака → замени [ТВОЁ ИМЯ] на своё
  • Прикрепи одну свою фотографию - хорошо освещённую, анфас
  • Отправь - все видео и картинки он сделает сам
06

Выложи в интернет

  • Напиши Клоду: «выложи сайт на Vercel» - он сам откроет браузер, подключится и задеплоит
  • Домен меняется в настройках Vercel
  • Не нравится что-то - гоняй туда-сюда: «замедли hero на 20%», «замени шрифт». Fable очень хорошо правит готовый сайт
